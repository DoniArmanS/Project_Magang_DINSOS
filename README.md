# Project_Magang_DINSOS

SIM-PPKS adalah platform manajemen data terpadu yang dirancang khusus untuk Dinas Sosial dan Pemberdayaan Masyarakat Kota Batam. Project ini dikembangkan sebagai solusi digital untuk menggantikan proses pendataan manual dan pengelolaan spreadsheet yang terpisah-pisah.
